Zero friction. Just ship.

Three concerns, solved once. Port conflicts, ugly URLs, and HTTPS warnings — gone before you open a browser.

Auto Port Assignment

Port in use? Harbormasterd finds an open one instantly. No more killing processes or rewriting configs.

*.pa.local URLs

Access services at myapp.pa.local instead of localhost:60001. Local resolver, zero hosts edits.

Automatic HTTPS

mkcert-backed certs issued on demand. No browser warnings, no manual trust steps after the first run.

// first voyage

Get under way in 30 seconds.

Install, start the daemon, configure trust + DNS once. Then forget it exists.

# quickstart — linux · macos · wsl

# 1. install
$ pip install harbormasterd

# 2. start the daemon
$ pad &

# 3. one-time setup — trust certs + install dns resolver
$ pa-platform tls trust
$ pa-platform dns install

# 4. run anything — port, dns, https handled
$ pa run --name=myapp --prefer=3000 -- npm run dev
→ https://myapp.pa.local
